# Quizmo Frontend

Application frontend du projet **Quizmo** développée avec [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/) et [Vite](https://vite.dev/).

## Installation

```bash
npm install
```

## Lancer le serveur de développement

```bash
npm run dev
```

L'application sera accessible sur `http://localhost:5173`.
Les requêtes vers `/api/*` sont automatiquement redirigées vers `http://localhost:8000` (backend FastAPI).

## Build de production

```bash
npm run build
```
